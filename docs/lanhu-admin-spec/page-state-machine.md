# Page State Machine

## 用户中心入口与入驻状态
- userHome
  - 进入：打开 `/pages/user/index`
  - 展示：用户资料、功能区入口、活动/动态区域
  - 可用操作：编辑资料、设置、点击 `我要入驻` / `主办中心` / `核销记录`、核销员点击左上角 `扫一扫`
  - 禁用操作：普通用户不可进入订单核销
  - 异常处理：入口权限不满足时隐藏入口或 Toast，不崩溃
- settlementApply
  - 进入：未入驻用户点击 `我要入驻`
  - 展示：暗色 UI 表单页，字段来自 mock 配置
  - 可用操作：填写表单、提交、返回
  - 禁用操作：重复提交
  - 异常处理：字段校验失败显示错误；提交失败 Toast/Dialog
- settlementSubmitting
  - 进入：点击 `提交申请`
  - 展示：按钮 loading/disabled
  - 可用操作：返回视产品确认，默认禁用重复提交
  - 禁用操作：再次提交
  - 异常处理：失败回到 settlementApply
- settlementPending
  - 进入：mock 提交成功
  - 展示：审核中状态页
  - 可用操作：我知道了、返回个人中心
  - 禁用操作：重复提交申请
  - 异常处理：无
- organizerApproved
  - 进入：用户状态为主办方 approved
  - 展示：用户主页第 5 项为 `主办中心`
  - 可用操作：进入后台管理
  - 禁用操作：不再显示 `我要入驻`
  - 异常处理：状态缺失时回退 settlementApply
- verifierActive
  - 进入：用户状态为 active 核销员
  - 展示：用户主页左上角 `扫一扫`，功能区可展示 `核销记录`
  - 可用操作：扫码核销、查看核销记录
  - 禁用操作：普通用户不可见这些入口
  - 异常处理：扫码取消/失败 Toast 或静默返回

## 管理后台（派对/活动）
- idle
  - 进入：页面挂载或返回当前内部视图
  - 展示：保持上一次数据或空壳布局
  - 可用操作：返回, 切换 tab
  - 禁用操作：提交类按钮，直到数据 ready
  - 异常处理：失败进入 error 或 Toast/Dialog
- loading
  - 进入：onLoad/onShow 或筛选搜索刷新
  - 展示：显示 loading 或骨架；设计稿未给出则使用 Taro.showLoading/局部 loading
  - 可用操作：返回
  - 禁用操作：重复提交, 删除, 审核
  - 异常处理：失败进入 error 或 Toast/Dialog
- loaded
  - 进入：数据加载成功且有数据
  - 展示：展示列表/表单/卡片
  - 可用操作：搜索, 筛选, 新增, 编辑, 下一步
  - 禁用操作：无
  - 异常处理：失败进入 error 或 Toast/Dialog
- empty
  - 进入：数据加载成功但列表为空
  - 展示：展示“暂无活动/暂无订单”等空态和必要 CTA
  - 可用操作：新增, 重置筛选
  - 禁用操作：列表项操作
  - 异常处理：失败进入 error 或 Toast/Dialog
- error
  - 进入：接口失败或数据解析失败
  - 展示：显示错误提示和重试入口；设计稿未给出，需最小实现
  - 可用操作：重试, 返回
  - 禁用操作：提交
  - 异常处理：失败进入 error 或 Toast/Dialog
- submitting
  - 进入：保存/新增/核销/删除确认后
  - 展示：按钮 loading 或禁用，Taro.showLoading
  - 可用操作：取消视具体操作而定
  - 禁用操作：重复点击提交
  - 异常处理：失败进入 error 或 Toast/Dialog
- dialogOpen
  - 进入：筛选、日历、核销、提现、添加核销员等弹窗打开
  - 展示：遮罩 + 面板
  - 可用操作：关闭, 确认
  - 禁用操作：底层滚动和底层点击
  - 异常处理：失败进入 error 或 Toast/Dialog
